# UI 开发约定

本项目沿用现有原生前端，不增加第二套组件库或图标系统。

## 样式与结构

- 使用已有 CSS 变量、Tailwind 构建期样式、浅色/暗色主题和移动端断点。不要重新引入运行时 Tailwind CDN。
- 使用本地 Lucide 图标和 `setUiContent` 等显式 API，保留 SVG 许可。不遍历/改写账号名、输入值或按钮中的任意用户文本。
- 原生 select 的 option 保持纯文本；装饰在控件外完成，程序切换模板时同步图标和颜色。
- 图标按钮有 title/可访问名称，按钮 `type=button`；装饰性 SVG 隐藏给辅助技术，不把 button/input/select 整体标成装饰。
- 动态内容按文字或安全转义显示；不要把别名、错误、资源名当作 HTML 注入。

## 交互

- 沿用 `data-act` 事件委托和显式 action 注册；不要新增内联 onclick 或放宽 CSP。
- 异步按钮使用可恢复的 busy helper，保留 DOM 节点、图标、原文字和焦点；accepted 分支也必须 finally 恢复。
- 任务列表默认收起，以图标/徽标提示。收起不取消任务、不丢失原幂等意图；过期轮询不能覆盖当前列表。
- 工具和自动化使用抽屉，不占据首页主体；高频动作保持易访问。
- 工作台保持非模态；保留拖动、键盘移动、视口约束、增量日志和阅读旧日志时不强制滚底的行为。
- 尊重减少动态效果和页面隐藏状态，取消 requestAnimationFrame ID 0 时也要有效，不制造重复动画循环。

## 配置与危险操作

- 草稿、已保存配置和 runtime 分离；保存使用 revision/代际基线，冲突先重读合并，不复用旧页面强覆盖。
- 删除/修复在确认时冻结目标身份；展示转义后的账号和资源，取消不发请求。
- 1101 保留受保护账号子域名的策略必须显式确认，不能取消后端中控 Worker/KV 保护。
- 账号移除说明“只移除中控配置”；不能让用户误以为删除了 Cloudflare 账号/Worker/KV。
- 诊断报告先脱敏，但仍提醒人工复核任意自定义凭据/源码；工作台日志不替代持久任务回执。

## 代码与验证

`frontend/modules` 放纯逻辑/协议，以依赖注入保持可独立测试；`frontend/js` 是兼容适配层。构建按明确顺序拼接，不引入第二套全局命名空间。

前端常规回归集中在 `frontend-ui`、`frontend-workbench`、`frontend-settings`、`frontend-task-flow` 四条流程；账号转移与模块构建另有专门测试。源码静态/VM 回归不等于屏幕阅读器、视觉、跨浏览器或 A5 验收。当前 CI 会执行 mock 浏览器回归；是否完成真实业务和辅助技术验收应另行记录。
